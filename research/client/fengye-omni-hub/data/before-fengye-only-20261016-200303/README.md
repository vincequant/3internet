# 風夜 · 全知情報 Hub 0.1.5（完整桌面版）

以「三國志全知情報 Hub 1.1.336」為底，保留原版全知功能，再加風夜情報與操控台。0.1.5 修正上一版停用原版功能的問題。

## 原版全知功能保持可用

保留勢力情報、勢力對比、武將資料、城池、部隊、訓練與募兵、外交、攻略預判、全景地圖，以及原版歷史回放、前後季切換、我方識別與資料源切換。完整保留原版輪詢、資料模型和渲染流程，不遮蓋或統一停用原版頁面；個別分頁的顯示條件沿用原版。

頂部「全知資料源」顯示目前使用的既有 Hub 來源。原版資料源設定首次使用時複製至本副本的私有 data/，切換不改原版設定。原版戰局檔案和歷史資料經私有路徑設定讀取，不搬動或覆蓋原存檔。本副本讀取既有採集橋；未啟動遊戲，也未新增遠端常駐。

風夜另有「風夜情報／操控台」分頁，內含情報、操控台、房間與來源記錄，以及風夜指令解讀。兩條來源分開顯示；風夜採集停止不會把原版全知資料清空，也不會停用全知功能。

## 風夜資料的使用

風夜收到的會話快照、訊框、同步記錄、聊天與控制回執都可查看、篩選及搜尋。同步封包經完整長度和 SHA 前綴校驗後，使用原版 native_command_evidence.decode 解析已知內政／外交／人事／出征封包；不由差分補造指令、結算結果或完整世界狀態。會話發送者與指令內勢力 ID 分開。

目前 run-093702 的 3 條完整同步記錄可解讀為兩條步兵訓練、一條騎兵訓練；尚未證明結算結果。八席開局快照與這幾條指令仍不能還原全部城池、武將和部隊。此缺口不影響原版全知功能繼續使用既有採集／回放來源；也不把另一來源的世界資料標成風夜獨立取得。

## 操控台

保留原有 chat／stop 單次操作。發言需 GBK 可表示、1–120 字、至少兩秒間隔，僅在線探針可用。待回執期間禁用再次操作，失敗或結果未知不自動重發；寫入成功與已執行回執分開。退出前由使用者確認。查房沿用既有中繼 SearchSession，不重新認證或入座。

## 啟動

- Wine 導航 →「打開風夜全知情報 Hub」。原版 Hub 入口保留。
- Mac：`啟動風夜Hub.command` 或 `python3 launch.py`。
- `python3 build_app.py` 安裝使用現有 Python 執行環境的原生 .app 入口。
- Windows：`启动风夜Hub.cmd`；需 Python、Tk、Pillow，尚未完成原生 Windows 實機驗證。
- `python3 run.py --replay /path/to/observation.json` 開啟風夜檔案回放，風夜控制禁用；原版全知資料源與回放功能仍獨立保持可用。
- `python3 run.py --archive /path/to/game-archive --seq 1` 直接開啟原版歷史局；可與 `--replay` 同用，明確區分兩份資料。

此為桌面程式，不開瀏覽器。全知頁讀取既有本機 API／已授權遠端來源，風夜頁請求驅動一次性 SSH 讀檔；不是新建網頁產品。視窗關閉後停止本視窗的輪詢，不退出遊戲或探針。

## 驗證和打包

```sh
python3 -m unittest discover -s tests
python3 run.py --replay data/last-observation.json --archive /path/to/existing-archive --seq 1 --verify-json data/full-hub-verification.json --verify-exit
python3 build_dist.py
```

UPSTREAM.json 保存複製時原版 SHA256；RELEASE.json 記錄桌面版與原版核心版本。發行包使用明確白名單並附 SHA256，排除 data/、連線設定、憑據、觀測快取、遊戲、存檔與執行環境。

本機以 Python 3.14／Tk 9／Pillow 驗證。後端保持 Python 3.8 語法；不宣稱整套原版 GUI 已在 Python 3.8 或 Windows 實機驗證。
