# 風夜情報台 0.2.32：指令隊列與原作全景地圖

本版處理按下指令後看不見排隊、建設無法明確選格、戰場細節不足，以及需要手動更新才讀取資料的問題。新版程式已加入對應流程；本輪指令驗證使用 Mock，地圖使用實際唯讀狀態，不以新實局指令驗收。

## 現行操作

外部指令只有七個按鍵：練步兵、練騎兵、練弓兵，以及建兵營（7）、馬房（8）、弓房（9）、陷阱（6）。練兵按一下即建立可見隊列記錄，不等待 Wine 執行後才顯示。沒有乘數、數值輸入、施捨／米交易／人事下拉或第二個送出步驟。

建設直接嵌在外部指令主頁：選種類，在同一張原全景大地圖選位置。不開城池小視窗，也不產生城池按鈕列。一次原始 terrain_grid 快照算出所有己方城池的既有 radius-4/type-2 候選，排除原始物件及隊列保留格；重疊格按距離與城池編號穩定歸屬，確認時顯示城名。可選格以透明綠框描邊，不以色塊蓋住地形。選建設時暫收合隊列，給原圖較大空間，處理中筆數仍顯示，亦可隨時展開；成功入隊會自動展開隊列。單擊只更新選取，按「確認位置並加入隊列」才建立指令；拖曳、縮放或單擊地圖都不會自行送出。位置在讀取失敗、城市切換或後續佔用時會失效，必須重新核對。已有物件及排隊／未觀測結果的建設格保持保留，避免同格重建。

隊列保留同一筆 ID、加入時間、勢力、位置、狀態與過程。尚無代送副作用的 `held/pending/validating/waiting_phase_exit/waiting_effect` 可撤回；`arming` 起不宣稱能安全撤回。同勢力不同兵種或建設可共用借席窗口依序處理，異勢力不並行切席。同勢力同兵種的前筆仍待核實時，後筆先等待並可撤回。

## 完成與未知的界線

本機發送回執與遊戲效果分開記錄。收到有效本機回執後顯示待核實，不能直接變成 `completed`；背景讀取新的原始風夜 Collector 快照，核對來源、時間、結構與前後變化後才完成；新樣本開始時間須晚於本筆真實回執觀測時間：

- 練兵使用對應 `entities.lords.armament_raw` 的步／騎／弓累積訓練值。固定 value 75 對應增加 30、上限 300；單靠金幣扣除、顯示百分比或本機回傳不算確認，300→300 也不算實際增加。
- 建設核對原本空格上出現唯一相符的新物件，包含勢力、座標、種類；兵營／馬房／弓房另核對所屬城池。原有物件、種類不符或同格多物件都不算本次完成。

這是同來源前後狀態的觀測證據，不能冒充原始指令或因果證明。未取得可核實效果時保留 `verifying`，顯示未確認且不重送；未知發送結果及未確認還席則暫停同來源後續代送，不任意還席。歷史資料重啟後只供查閱，不會重新建立可執行隊列。

三個隊列分頁只顯示當局：`game_key` 由實際 Collector 的 PID、進程建立時間、路徑、核心、版本、劇本及名單等穩定事實計算，不含每次取樣時間、借席狀態或隨機 token。同一身分跨面板重啟保持相同 key；沒有 key 的舊記錄、legacy 及不同 key 全部留在私有審計歷史，不出現在當局列表，也不自動匯入舊檔。

發送準備前、等回合後及基準取樣後再次核對局身分；確定換局便取消舊局未發送請求。同進程的未知待發 agent 即使核心已換也不能視為已結束，仍暫停後續。Collector 尚無原始獨立局 ID，完全相同進程／核心／劇本／名單重用無法保證辨新局；名單真變更也可能保守隔離舊請求，沒有補造局身分。

`data/command-history.json` 留本機、排除發行包。`legacy_command_history.py` 僅保留為離線審計工具，正式面板不呼叫。畫面採玩家用語：真玩家・勢力名、實際城名，以及訓練度／金前後數字或同格新增建物；內部狀態碼、回傳碼、執行緒與核心位址留審計檔。

## 地圖、讀取與圖標

`fengye_battle_panel.py` 為本 Hub 專用接入模組，名稱與原版 `app/battle_panel.py` 分開，避免載入衝突。它使用原全景地圖 renderer，而非以點或方塊代替全部物件；城池、兵種 sprite、旗幟、補給線、格線及可核實的 HP／士氣等資訊沿用原繪製路徑。原始快照與顯示投影分開，顯示補充不回寫證據。

工具列移除上方對手選擇、城池搜尋定位、可產兵閾值及「展開對手狀態」；選城不自動開側欄。陷阱保持顯示且不提供開關，僅留「文字」checkbox。保留縮放、平移與獨立地圖，縮放按鈕使用深色文字。建設選址共用原全景視角及座標投影，透明綠框畫在實際地形上。

戰場、外部指令及選址預設每 3 秒自動讀取，採背景單工與共用快取；未完成的讀取不重疊啟動，過期回覆不覆蓋新選取。來源固定風夜影子客戶端，讀不到就顯示未知／失效，不回退其他玩家。關窗停止相關輪詢，回放模式不發出實際指令。

新圖標使用內建 image_gen 生成，來源及提示詞保存在 `assets/fengye-icon.png`、`assets/fengye-icon.prompt.txt`；僅以尺寸轉換產生 PNG／ICO／ICNS。`fengye_icon.py` 與 `.app` 使用自有圖標，不改共用 Wine／遊戲圖標。
