# 三国志 Hub 统一版

Mac 本机连接自己的 CrossOver 采集桥；Windows 本机连接原生采集桥；远端 Mac 经 Tailscale IPv6 的 SSH 隧道查看源 Mac。界面显示机器来源；远端禁用修改源端我方身份。源游戏需要处于已选择玩家的对局中。主机睡眠、Tailscale 不在线时显示断开，恢复后自动重连。

`connection.local.json` 是机器专属配置，不进入发布包。远端专用 SSH 密钥保存在该 Mac 的 `~/.ssh/sgi_hub_ed25519`，源端只允许转发指定 loopback 接口。不要复制现有用户私钥。

启动：Mac 双击 `Start-Mac.command`，Windows 双击 `Start-Windows.cmd`。整局回放用 `Start-Replay` 或 Wine 导航「打开历史回放」，不启动游戏。远端不需要游戏或 CrossOver。不要同时启动多个远端 Hub 占用同一端口。关闭远端窗口会退出它建立的隧道。房间人数和安静等待在 Wine 导航（Mac 三国志 Wine.app 或 `Start-Wine-Nav`）。全景地图在 Hub 顶栏「全景地图」标签，Wine 启动器里仍可打开独立视窗。

自动识别来自游戏当前玩家槽，每次重新读取；无有效槽时显示未确认，不能猜。全图城关显示按当前人口与关联建筑计算的单次征兵能力，单位为人，不是库存，不表示当下必定可执行征兵。人口小于 50000 时为 0；门槛以上人数上限按游戏 MulDiv 取整，最多 50000，再与本城对应兵种建筑总值取较小者。关隘不适用。未知字段不显示成零。
