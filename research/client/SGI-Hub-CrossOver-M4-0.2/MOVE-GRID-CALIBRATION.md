## 1. 现行规则（已用 3 个真实场景逐格验证为零差集）

代码在 `app/unit_move.py`，核心 `reachable_cells` = Dijkstra，进格消耗制：

`move_overlay_cells` = reachable − 原点 − 己方城格 − 建筑格。己方城与建筑一样可穿行，不再进城即止。

已废弃的错误方案（不要走回头路）：
- polyline（city_roads.json）当路：折线抄近角，把西北丘陵划成路。
- 五点采样判路：漏掉细路（东北通海岸路臂断掉）。
- 纯色占比≥3% 判路：干草沙斑误判（西侧多画一片）。
- 纯暖色 R−G≥10 占比：阈值 0.024 vs 0.028 无法分割沙斑与细路。
- 暖色兜底（路色且 R−G≥10 占格 ≥5%）：蓟南干草沙斑暖像素 5–24%，把团块沙斑救回成路，南侧多画两格。
- 建筑占格不可穿：pair2 证伪。
- 己方城进城即止：平原城在骑兵范围正中，城东海岸游戏仍有格，穿城才能走到。

## 2. 标定方法论（怎么发现并证明规则错了）

原则：**不要目测比格子**，人眼在等距斜视角下必错。全部程序化：

1. **拿同一时刻的状态**。截图时间戳 vs `history-data/<identity>/last.json` 的 snapshot_id；部队若在截图后又动了，用 `changes.jsonl` 里的 `部队坐标 before/after` 回放（工具的 `--move UID:X,Y`）。
2. **锚定晶格**。截图里找红/品红图标（ENTER、攻击标，质心≈所在格中心），该格世界坐标已知（如南皮 70,38）。世界像素 `wp(x,y)=(48+96x+48*(y%2), 24+24y)`，screen = wp*S − off，S 为游戏缩放（见过 1.56–2.0），对 S 和图标偏移 ±16px 联合搜索取分数最大。没有图标锚点的截图基本废，请用户重截或换有 ENTER 的那张。
3. **逐格判"游戏画没画"**。青色点阵判别式（画格 0.2+，草地 0.00）：`(B−R∈[12,70]) & (G≥140) & (R≥110) & (B≤235)`，格内内接盒平均分≥0.10 判画。
4. **剔脏格再比**。部队精灵、血条（紫/蓝）、旗、建筑、图标覆盖的格分数不可信，先排除。
5. **与 Hub 差集**。`hub多画`（要收紧规则/成本）与 `hub漏画`（要放宽）分开看，并打印每个差格的地形判定与剩余 MP——差格全是"花费 10–12 的边缘格"= 成本差一档；差格聚在某单位周围 = 阻挡/ZOC 规则；差格在建筑后方 = 穿行规则。
6. **规则变体矩阵**。对候选规则组合（如 zoc×建筑×城 3×3×2）在**所有历史场景**上算总 symdiff，取全局最优，防止修新场景弄坏旧场景。已验场景务必保留在测试或本文档中。
7. **改完必须回归全部场景 + `python3 -m unittest test_unit_move test_panorama_map`**。

一键工具：`bridge/move_grid_calibrate.py`（本目录）：

```
python3 bridge/move_grid_calibrate.py 截图.png history-data/<id>/last.json 31 \
    --anchor-cell 70,38 --move 31:69,32 --move 68:68,34
```

## 4. 已知边界与后续方向

- 地形优先用采集器 `terrain_grid`（`0x469f6f` cell+0x0a）。码表：1=丘陵，3=山岳且不可进（洛阳南灰岩；小地图会判平地/路），**例外**：四邻有城/关且 `hill_sample` 不足 3 点的草坡按平地（虎牢南坡 (54,83)，否则程普 18 点出不了关；关西 (53,81) hill≥3 仍是山）。4/6=河川（黄沙岸仍可走，平原 (70,56) 引擎是 4），7–14=道路（函谷/虎牢 type 7 小地图是丘陵）。城格引擎不是 7–14 时不走路价（襄阳 type 0 屋顶会被判路，12 点步兵会多踩南坡第二格；弓兵从邻格上坡不受影响）。2 混杂，仍走像素。15 采集失败走像素，不要把两点邻水的 15 填成河（晋阳东岸 (50,45)(50,48) 是 15）。无表时整格走 MBM。不要把青绿改成全局河川。攻略写山岳耗 6，洛阳实机灰岩无格，按过不去处理。不要把 type 3 全局改回平地，也不要用两点邻水填 15。
- 骑兵/水军/粮车的 MP 与技能修正只验证过步兵 12MP 场景，其他兵种出错优先怀疑 `move_points`/`unit_has_horse`/`unit_has_navy`。
- 桥梁（TERRAIN_COST 桥4）从未被真实场景踩到过，属未验证项。
- `_road_shape_frac` 每格 ~40ms（有 terrain 级缓存，且只对路色≥2% 的格触发）。若卡顿，先查缓存是否失效。
