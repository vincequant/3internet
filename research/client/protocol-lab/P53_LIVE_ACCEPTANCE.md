# 新房逐项验收清单（当前全部未执行）

不要把旧局残留、合成 GUI 或离线 x86 测试填为活局通过。只在自有内测新房试验。每个元素分开做“关闭→开启→关闭”；任何 lag/RX/崩溃退化先保存现场，再关闭刚开启的元素；不调用 SetEvent、不清队列、不重发回合、不自动重启/收线。

## 每局基线

- [ ] 用户已建立新房；记录房间/run、主机身份/IP、两端 Wine PID/creation、SANPK/DLL SHA、采样器版本、原始开始/结束时间。两端时钟采样有时间戳，不能只凭 `connected=1` 判同步。
- [ ] P51 干净常驻驱动已先独立通过；单驱动/in-flight、收据与回合推进正常。全新 UI 状态文件，不沿用旧局地址/借用席位。
- [ ] 所有 P52/P53 字节 `check` 无 unexpected；C 扩展 mask=0/code_addr=0（若前次已分配，mask=0即可，洞穴不释放）。D 未打开或查阅停止。
- [ ] 原始 RX 记录/帧序/到达时间在增长，主机确有广播；队列 `84b4=0` 不能单独当作 RX 正常。先录至少五个真实推进回合，记录最大包间隔、序号、接收条数及队列轨迹。
- [ ] 两端原始 world tuple/年/季/phase/回合收据相互对齐，至少五回合 `lag≤1` 且不增长。跨季/跨年用原始元组和收据对齐，不能把年份/季节直接相减当“回合 lag”。`lag_watch.py` 的历史 `f_4d4` 当前 roundprobe 未输出，该字段为空时不得当作 0 或有效 lag。
- [ ] 影子 `3I/sgi-crash-context.bin` 记录 size/mtime/SHA 并复制基线，保留 SEH stderr 和已有 flight records。只记录旧台账大小不算零新增。
- [ ] 同步保存同一地图区域/视角/图层/缩放截图、`p52_panel_snapshot.py`、本次实体快照。截图失败就写失败；不填“已目视”。

可复用 `tools/roundprobe.py --bridge "$Z\\bridge" --samples 1` 分别在主机和影子 prefix 读取原始元组；使用本局目录留存 stdout/stderr。既有 `lag_watch.py` 可作辅助，不能替代原始 RX 或校准回合。

## 每次切一个元素的共同记录

将下列字段记到 `acceptance-template.csv` 的对应行；每项至少五个真实回合，另留跨季/低缩放组合测试。没出现该元素时填“未覆盖”，不填通过。

| 阶段 | 需要保留 |
|---|---|
| before（关闭） | 字节 check、原始字段/对象 raw SHA、画面、RX 原文件偏移/计数/最大间隔、两端 tuple 与收据、崩溃 size/mtime/SHA |
| on | 单项 switch receipt；其他元素开关状态；同坐标/图层/缩放画面与字段对应；同一组健康指标 |
| off | 该项恢复原始/封印字节；其他项仍保持；画面变化与健康指标；A 创建控件的生命周期例外单列 |
| 结论 | 通过/失败/未覆盖/未知、观察时段、lag 是否增长、RX 是否有缺口、崩溃新增字节、原始证据路径 |

## 退化处理

先冻结本局观察日志、两端原始 tuple/收据、RX 尾段、崩溃增量、当前字节和截图（失败也留回执），再 `--action off --element <刚开启项>`；D 则停止查阅/关窗。复读其他项字节与 RX，记录回滚是否恢复。如果结果未知，不重复输入、不清 busy/接收队列、不自动换房。
